# 数学知识点总览

本知识库覆盖**高中数学课内全部内容**（人教 A 版 2019 新教材：必修第一册、必修第二册、选择性必修第一、二、三册），不含竞赛与强基拓展内容。

每个专题按**节**组织，**每节标注两个维度的星级（最多 5 颗星）**，节内每个知识点另行标注难度；并配有函数图象、平面几何、立体几何直观图等 SVG 插图。

## ⭐ 星级说明（难度 / 重要性）

| 维度 | 含义 |
|------|------|
| **难度** | 该节内容本身的思维与综合程度（做题时的门槛） |
| **重要性** | 高考考频与分值权重（复习投入的优先级） |

**难度**分级：

| 星级 | 含义 |
|------|------|
| ★☆☆☆☆ | 识记了解：直接识别、直接套用 |
| ★★☆☆☆ | 基础理解：概念清楚即可得分 |
| ★★★☆☆ | 常规应用：中档选择、填空的主力 |
| ★★★★☆ | 综合应用：多知识点联动，解答题主干 |
| ★★★★★ | 压轴难度：导数、圆锥曲线、新定义等区分度考点 |

**重要性**分级：

| 星级 | 含义 |
|------|------|
| ★☆☆☆☆ | 低频考点：偶有涉及 |
| ★★☆☆☆ | 小题点缀：偶尔出现 |
| ★★★☆☆ | 常规考点：年年有涉及 |
| ★★★★☆ | 高频考点：选择填空常客或解答题常见步骤 |
| ★★★★★ | 核心必考：大题主干或每年必考的基石内容 |

**表示方法示例**（每节开头一行）：

> **难度**：★★★★☆　**重要性**：★★★★★
